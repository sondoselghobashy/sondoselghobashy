Software Engineer → AI / ML Engineer

Software engineer with 7+ years of professional experience building backend systems and web applications, now working at the intersection of software engineering and machine learning. What I care about: production-quality code, honest evaluation, and AI systems that actually work when the data is noisy and half of it is missing.
